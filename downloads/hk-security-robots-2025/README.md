# 香港2025年保安機械人部署研究

[下載 Excel：香港2025年保安機械人部署研究.xlsx](香港2025年保安機械人部署研究.xlsx?raw=true)

整理香港在2025年期間的保安機械人現場應用、試行及示範。Excel 包含客戶／使用方、保安公司、機械人方案供應商、品牌／型號、月份及來源連結。

- 11 項現場紀錄：4 項實際使用、3 項現場試行、4 項現場示範。
- 7 項採購／交付協議、計劃及待核實線索。
- 29 個來源，附發布日期、段落定位及讀取情況。

實際使用不等於已證實付費商業化；未披露的買方、保安承辦商、品牌及部署月份均已標明。港仔機器人（0370.HK）的採購及預定交付另列，未當作2025年已部署。跨年部署及報道月份亦與首次啟用時間分開。
